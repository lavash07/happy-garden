# Для моделі в цьому репозиторії

Працюй лише в папці, яку назвала людина з команди. Спочатку прочитай її `TASK.md`, потім `docs/ARCHITECTURE.md`.

`app/contracts` уже зібраний. Нові класи даних поруч зі своїм кодом не створюй. Якщо не вистачає поля, запиши це в `NOTES.md` своєї папки.

Формули росту живуть у `docs/RULES.md` і в `app/core`. `app/contracts/fakes.py` — вітрина для екранів.
