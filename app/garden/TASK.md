# Людина 3 — карта

Прочитай `CONCEPT.md`, розділ «Карта» в `docs/ARCHITECTURE.md` і цей файл.

Працюй у `app/garden`. Оболонку, рушій, базу і контракти не змінюй. Стан рослин не перераховуй: бери стадію, настрій і координати з `ZoneView`.

Клас `GardenMap` уже має конструктор `(on_select_pot, on_move_pot)`. Реалізуй `control`, `show`, `spawn_point`. Конструктор збігається з фабрикою, яку `main.py` передасть в оболонку.

## Камера

Константи зуму і світу бери з `app.contracts.constants`: `MIN_ZOOM`, `MAX_ZOOM`, `ZOOM_STEP`, `WORLD_SIZE`, `HIT_SIZE`.

```text
screen_x = (world_x - center_x) * zoom + width / 2
screen_y = (world_y - center_y) * zoom + height / 2
world_x = (screen_x - width / 2) / zoom + center_x
world_y = (screen_y - height / 2) / zoom + center_y
```

Тягнення пальцем або мишею рухає центр так, щоб грядка їхала за пальцем. Кнопки `BTN_ZOOM_IN` і `BTN_ZOOM_OUT` множать зум на `ZOOM_STEP` і затискають його в межі. Жест щипка можна додати в кінці, демо не має від нього залежати.

Перший `show` ставить центр на середнє `x, y` горщиків. Якщо горщиків немає — центр `WORLD_SIZE / 2`. Наступні `show` змінюють рослини і не чіпають камеру.

`spawn_point` повертає поточний центр світу, щоб нова рослина з'явилася на екрані.

## Фон

## Горщик

`sprite_for` у `sprites.py` повертає `SpriteSpec` за таблицею. Flet там не імпортуй.

| Стадія | Прогрес | Масштаб | Плодів |
| --- | --- | --- | --- |
| sprout | < 0.5 | 0.45 | 0 |
| sprout | ≥ 0.5 | 0.6 | 0 |
| growing | будь-який | 0.8 | 0 |
| flowering | будь-який | 0.9 | 0 |
| fruiting | будь-який | 1.0 | 2 |
| ripe | будь-який | 1.2 | 3 |
| harvested | будь-який | 0.45 | 0 |

Личко: `happy` посмішка, `ok` риса, `thirsty` кружечок, `sad` сумний рот. `droop=True` для `thirsty` і `sad`. На цвітінні додай жовту крапку і не малюй плоди. Плоди мають те саме личко. `glyph` і `color_hex` бери з довідки культури. `title` — її назва.

На карті розмір цілі натискання не менший за `HIT_SIZE`. Якщо довідки для горщика немає, малюй `🌱` і колір `#9E9E9E`.

Натискання викликає `on_select_pot(id)`. Перетягування рухає горщик на екрані одразу, а `on_move_pot(id, world_x, world_y)` кличе один раз у кінці жесту.

Групу малюй рамкою навколо її горщиків із запасом 24 світові одиниці і заголовком зверху. Рамку рахуй із поточних координат, не з збереженого центра групи.

Анімація поливу — додаткова. Для здачі достатньо нового личка після `show`.

Свій демо-запуск: `flet run app/garden/demo.py`. Покажи в ньому `sample_zone_view()` з `app.contracts.samples`, щоб було видно групу огірків, спраглий горщик і сумний помідор.
