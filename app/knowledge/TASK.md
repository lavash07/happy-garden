## Довідка — `catalog.py`

Файл JSON має вигляд `{"species": [ ... ]}`. Кожен об'єкт розбирай через `species_from_dict`. Читай файл у `search` і `find`, щоб правку JSON було видно без перезапуску.

Ключі зафіксовані парсером. Нові поля в об'єкт не додавай. `verified: false` лишай, доки немає реального URL.

`search`: порожній запит повертає всі записи. Інакше шукай без урахування регістру в назві, `species_id` і сорті.

`find`:

- збіг за `species_id` або за українською назвою;
- якщо просять сорт і такий запис є, повернути його;
- інакше повернути загальний запис цього виду і підставити в поле `variety` назву, яку просила людина;
- якщо збігу немає — `SpeciesNotFound`.

До захисту в JSON мають бути огірок, помідор і полуниця. Числа і `summary` заміни на факти з відкритої агрономічної сторінки. У `sources` впиши справжній URL сторінки, з якої взято числа. Після цього постав `verified: true`. Вигаданий URL не вписуй: краще лишити `verified: false`.

Чернетку огірка, яка вже лежить у файлі, можна замінити. `species_id` лишаються `cucumber`, `tomato`, `strawberry`.

## Погода — `weather.py`

`httpx` імпортуй усередині методу. Ключ API не потрібен.

Геокодинг:

```text
https://geocoding-api.open-meteo.com/v1/search?name={territory}&count=1&language=uk&format=json
```

Прогноз:

```text
https://api.open-meteo.com/v1/forecast?latitude={lat}&longitude={lon}&daily=temperature_2m_min,temperature_2m_max,precipitation_sum&timezone=auto&forecast_days=2
```

Таймаут 8 секунд. Координати місцевості кешуй у `self._geo_cache`.

Порожня місцевість дає порожній список. Будь-яка мережева помилка дає один `WeatherAlert` рівня `info` з текстом `OFFLINE_WEATHER` і часом `now`, застосунок при цьому не падає.

Винеси чисту функцію `alerts_from_daily(daily, species, now)`, щоб тести не ходили в мережу. `alerts` лише дістає JSON і кличе її.

Правила за перші дві доби:

- мінімум `<= 2` → `danger`, заголовок `Мороз`, порада `Накрий рослини або занеси горщики в тепло`
- максимум `>= 32` → `warning`, `Спека`, `Полий зранку і притіни`
- опади `>= 10` мм → `info`, `Дощ`, `Сьогодні можна не поливати`
- мінімум нижчий за `species.temp_c[0] - 3`, і це ще не мороз вище → `warning`, `Холодно для {name}`, `Поки що не тримай рослину просто неба`

Можна повернути кілька попереджень. `starts_at` — переданий `now`.

## Перевірка

Додай тести на пошук огірка українською назвою, на невідому культуру і на `alerts_from_daily` для морозу, спеки і дощу. Мережу в тестах не викликай.
