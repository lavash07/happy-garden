Картинки не обов'язкові для хакатону.

Якщо файл є, карта може взяти його замість значка:

`assets/plants/{species_id}/{stage}_{mood}.png`

Приклад: `assets/plants/cucumber/ripe_happy.png`

`stage` — значення GrowthStage: sprout, growing, flowering, fruiting, ripe, harvested.
`mood` — happy, ok, thirsty, sad.

Поки файлу немає, город малює glyph і обличчя з коду.
